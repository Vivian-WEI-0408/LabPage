WIKI ENGINE / 功能介绍

Get Started

ChenLab Wiki 由 LeoMoon Wiki-Go 驱动，为实验室知识的编写、协作、查找与长期维护提供完整工具。

01

内容管理

使用 Markdown 编写富文本内容，支持 Emoji 短代码、附件上传、层级目录、文档创建编辑，以及完整的版本历史与旧版本恢复。

  • Markdown & code blocks
  • Files & attachments
  • Version history
02

协作与反馈

通过文档评论开展讨论，评论同样支持 Markdown；管理员可以审核内容，也可以根据需要全局关闭评论。

  • Document comments
  • Markdown feedback
  • Comment moderation
03

搜索与导航

全文检索支持精确短语、词语包含或排除和结果高亮；面包屑与侧边栏用于快速定位知识库中的文档层级。

  • Full-text search
  • Breadcrumbs
  • Sidebar navigation
04

科研写作体验

提供响应式界面和深浅主题，支持多语言代码高亮、MathJax 数学公式与 Mermaid 流程图、时序图等科研表达方式。

  • Syntax highlighting
  • LaTeX / MathJax
  • Mermaid diagrams
05

管理与权限

管理员可创建不同权限级别的用户，通过管理面板配置 Wiki、查看使用统计，并设置文档访问规则。

  • User management
  • Access rules
  • Site statistics
06

高级功能

自定义 Markdown 短代码、媒体嵌入和打印样式可扩展文档能力；REST API 支持以程序化方式访问实验室知识。

  • Custom shortcodes
  • Media embedding
  • REST API
